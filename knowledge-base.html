End-to-End Loan Origination Data Flow: Encompass ↔ Cotality ↔ Lender Price

Owner: Enterprise Data Architecture
Last updated 2026-07-14 · Version 3.2 · Channels: Consumer, Correspondent

1. Overview

This document defines the canonical data flow for a residential mortgage loan file from initial product/pricing selection through rate lock confirmation and core loan boarding. Three systems of record participate: Lender Price (product eligibility and pricing engine, "PPE"), Cotality (secondary marketing pricing and lock desk system, formerly CoreLogic pricing/locking services), and Encompass (Ellie Mae/ICE Mortgage Technology core Loan Origination System, "LOS"). Consumer Lending originates loans directly via retail/digital channels into Encompass; Correspondent Lending ingests closed/delegated loan files from correspondent sellers, reconciling pricing and lock data against the same Cotality/Lender Price backbone before boarding into Encompass.

2. Sequence of Record

  1. Product Eligibility & Initial Pricing (Lender Price): Loan officer or borrower-facing digital app submits a pricing request (loan amount, FICO, LTV, occupancy, property type, state) to Lender Price via REST API. Lender Price returns eligible products, note rates, and rebate/points across investor overlays.
  2. Product Selection Feed to Encompass: Selected product/pricing scenario is written back to Encompass loan fields via the Encompass Developer Connect (EDC) API, populating the 3.4 pricing fields and custom fields (CX.*).
  3. Lock Request Routing (Cotality): When the borrower/LO requests a lock, Encompass triggers a lock request event (via Encompass Business Events + webhook) to Cotality's lock desk API, carrying the Lender Price product ID, rate, and lock period.
  4. Lock Confirmation Push: Cotality validates against current secondary market pricing, confirms (or re-prices) the lock, and pushes the confirmed locked rate, lock expiration date, and investor commitment ID back into Encompass via SOAP/REST integration on a scheduled 15-minute polling interval plus real-time webhook on status change.
  5. Underwriting Handoff: Encompass exposes the fully priced and locked loan file to underwriting/AUS (DU/LPA) and downstream conditions engines.
  6. Correspondent Variant: For Correspondent Lending, the seller's closed loan file (ULDD/MISMO 3.4 XML) is ingested into Encompass via the Correspondent Import Service; pricing/lock data is reconciled against Cotality's investor commitment record rather than generated fresh, with exceptions routed to a pricing analyst queue.

6. Exception Handling

Pricing mismatches between Lender Price's quoted rate and Cotality's confirmed lock (tolerance > 0.125 bps) trigger a PRICE_EXCEPTION event routed to the Secondary Marketing exception queue. FICO or DTI deltas discovered post-lock (re-verification) trigger a RELOCK_REQUIRED workflow in Encompass, invalidating the current Cotality investor commitment and re-initiating step 1.

Consumer Lending Channel Guide

Last updated 2026-06-30 · Version 2.1

Consumer Lending covers retail branch and direct-to-consumer digital origination. Borrowers or loan officers initiate applications through the Chase MyHome digital portal or branch-based Encompass workstations. All product eligibility and pricing calls originate from the borrower-facing UI directly against Lender Price, with results streamed into Encompass in real time.

Key Characteristics

  • Loan officer assisted or self-service digital application intake (1003/URLA).
  • Real-time pricing refresh every time a material loan characteristic changes (loan amount, FICO tier, LTV band).
  • Lock requests initiated directly from the Encompass Pipeline UI, routed automatically to Cotality.
  • SLA: Pricing eligibility response < 2s; lock confirmation < 5 min during market hours.

Correspondent Lending Channel Guide

Last updated 2026-06-30 · Version 2.0

Correspondent Lending purchases closed, funded loans from approved correspondent sellers. Loans arrive as MISMO 3.4 XML packages via SFTP and are ingested through the Correspondent Import Service into Encompass. Because the loan is already priced and locked by the seller, Cotality performs a reconciliation pass against the seller's stated pricing rather than generating an original quote.

Key Characteristics

  • Batch ingestion cadence: hourly import windows, 06:00–20:00 ET.
  • Pricing reconciliation tolerance: 0.125 bps before manual exception review.
  • Lender Price used for post-purchase eligibility audit, not original quoting.
  • SLA: Import-to-board cycle time < 4 business hours.
